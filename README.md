# Small Language Model

A decoder-only transformer language model trained from scratch on the [TinyStories](https://huggingface.co/datasets/roneneldan/TinyStories) dataset.

## Model Architecture

- Decoder-only transformer (GPT-style)
- 6 layers, 8 attention heads, 256 hidden dimensions
- 512 token context window
- ~8-10M parameters
- Trained with causal language modeling (next-token prediction)

## Quickstart

### Install

```bash
git clone https://github.com/shakeermohammed1/small-language-model.git
cd small-language-model
pip install -r requirements.txt
pip install -e .
```

### Download Data

```bash
python scripts/download_data.py
```

Downloads ~2.1M short stories from HuggingFace into `data/raw/`.

### Train

```bash
python scripts/train.py --config configs/model_config.yaml
```

### Generate Text

```bash
python scripts/infer.py --checkpoint models/checkpoints/epoch_1.pt --prompt "Once upon a time"
```

## Train on RunPod

1. Create a pod on [RunPod](https://runpod.io) with a PyTorch template (RTX 3090 or A100)
2. Open the terminal and run:

```bash
bash <(curl -s https://raw.githubusercontent.com/shakeermohammed1/small-language-model/main/scripts/runpod_train.sh) https://github.com/shakeermohammed1/small-language-model.git
```

This will clone the repo, install dependencies, download the data, and start training automatically.

## Dataset

[TinyStories](https://huggingface.co/datasets/roneneldan/TinyStories) — a synthetic dataset of short stories generated by GPT-3.5/GPT-4 using vocabulary understandable by 3-4 year olds. Used as a compact corpus for training and evaluating small language models.

## Training Config

| Parameter | Value |
|---|---|
| Epochs | 10 |
| Batch size | 16 |
| Learning rate | 3e-4 |
| Optimizer | AdamW |
| LR schedule | Cosine annealing |
| Gradient clipping | 1.0 |
| Warmup steps | 100 |
